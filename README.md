# Mental Health Survey

A Next.js survey application with a server-only submission route that sends
anonymous responses to Google Apps Script and Google Sheets.

## Deploy

Upload every file in this folder directly to the root of the GitHub `main`
branch. In Vercel, keep the Root Directory as `./` and follow
`VERCEL_DEPLOYMENT.md`.

The root `package.json` is genuine JSON and must begin with `{`.
